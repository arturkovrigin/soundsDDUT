ГОЛОСА ДВОРЦА

Готовая структура для GitHub Pages.

Как загрузить:
1. Открой репозиторий soundsDDUT
2. Загрузи папку golosa-dvorca в корень репозитория
3. В каждую папку кабинета добавь свой аудиофайл с названием audio.mp3
4. Проверь ссылки
